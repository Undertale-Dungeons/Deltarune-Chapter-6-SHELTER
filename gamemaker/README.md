# DELTARUNE: SHELTER — GameMaker build

This is a standalone fan-game project, not a patch for the official DELTARUNE installation.

## Open it

1. Install GameMaker.
2. Open `SHELTER.yyp` from this folder.
3. Let GameMaker import the project.
4. Run it with the desktop target.

## Controls

- Move: WASD or arrow keys
- Interact / confirm: Z, Enter, or Space
- Battle selection: arrow keys
- Enemy-turn dodge: WASD or arrow keys

## Current prototype

- Hometown opening
- Bunker entrance sequence
- Mirror room and ENTRY 1
- Ralsei encounter scene
- Original boss encounter with ACT, FIGHT, ITEM and CHECK
- A short dodge phase and ending

## Important

This is an early source project. It has not yet been opened or compiled in the GameMaker IDE, so the first IDE import may reveal project-format or GML issues that need fixing. The visuals are procedural placeholders, not final pixel art.

Use original artwork, music and writing. Do not copy official game assets or present this as an official release.
